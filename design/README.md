# JustApps Logo-Dateien

Alle einzeln nutzbaren Varianten liegen in `logos/`, jeweils als SVG und PNG.
Eine Übersicht bietet [logos/variants-preview.png](logos/variants-preview.png).

| Verwendung | Datei (jeweils .svg / .png) |
| --- | --- |
| Repo-/Organisationsavatar | `justapps-avatar-blue` |
| Avatar mit dunklem / hellem Hintergrund | `justapps-avatar-dark` / `justapps-avatar-light` |
| Homepage auf hellem Hintergrund | `justapps-lockup-light` |
| Homepage auf dunklem Hintergrund | `justapps-lockup-dark` |
| Einfarbige Kombination aus Zeichen und Schrift | `justapps-lockup-black` / `justapps-lockup-white` |
| Einzelnes Zeichen, transparent | `justapps-mark-blue` / `justapps-mark-black` / `justapps-mark-white` |
| Abgerundetes App-Icon | `justapps-icon-blue` / `justapps-icon-dark` / `justapps-icon-light` |

## Formate

- SVG: frei skalierbar; die Schrift ist in Pfade umgewandelt, keine Schriftinstallation erforderlich.
- PNG: Zeichen, Icons und Avatare in 1024 × 1024 px; Kombinationen mit Schrift in 2400 px Breite.
- Zeichen und Schriftkombinationen haben transparente Hintergründe, auch die Variante `lockup-dark`.
- App-Icons haben transparente Ecken. Avatare sind vollflächig quadratisch für Plattformen, die selbst rund zuschneiden.
- `light` / `dark` bezeichnet bei Schriftkombinationen den vorgesehenen Hintergrund; bei Icons und Avataren die tatsächliche Hintergrundfarbe.

## Farben

- Markenblau: `#4655F5`
- Blau für die Schriftkombination auf dunklem Hintergrund: `#7B85FF`
- Dunkel: `#171923`
- Hell: `#F7F7F2`
- Weiß: `#FFFFFF`

Die Übersichten in `branding/` und `logos/variants-preview.png` dienen der Vorschau. Für die Einbindung die einzelnen Dateien verwenden. Rund um das Logo mindestens die Breite des quadratischen j-Punkts freihalten; Proportionen beibehalten.
