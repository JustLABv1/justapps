Integration settings are stored in PostgreSQL and managed after the base deployment is healthy. The encryption secret from the deployment layer must remain stable across restarts, upgrades and restores.

## Safe rollout order

1. Configure the provider-encryption secret in Compose or Helm.
2. Add a provider with the smallest useful permissions.
3. Use the provider test or a non-production app link.
4. Check logs, sync status and access boundaries.
5. Rotate the token through the admin UI when required.

Provider credentials are not public frontend settings. Do not paste them into app Markdown, repository files or screenshots.
